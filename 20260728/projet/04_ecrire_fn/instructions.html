Exercice 4 / 6 — Fichiers

Fonction pour écrire

function + write

Le concept

Même idée pour l'écriture : une fonction reçoit le chemin et le texte, et écrit le fichier.

function ecrire(chemin, texte)
  local f = io.open(chemin, "w")
  f:write(texte)
  f:close()
end

Instructions

Project Zomboid : tu sauvegardes des infos dans des fichiers nommés.

Écris function ecrire(...) — sans local.

La fonction ecrire

Elle reçoit deux paramètres. Le premier s'appelle chemin — le nom du fichier. Le deuxième s'appelle texte — ce qu'il faut écrire dedans.

Elle ouvre le fichier en mode écriture, écrit texte, puis ferme. Elle n'a pas besoin de retourner quoi que ce soit.

ecrire("save.txt", "Joel")
