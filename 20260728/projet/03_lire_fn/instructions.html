Exercice 3 / 6 — Fichiers

Fonction pour lire

function + io.open

Le concept

Tu ranges la lecture dans une fonction : tu lui passes le nom du fichier, elle te renvoie le texte.

function lire(chemin)
  local f = io.open(chemin, "r")
  local texte = f:read("*a")
  f:close()
  return texte
end

Instructions

GTA : le jeu charge des notes d'inventaire depuis différents fichiers.

La fonction lire

Elle reçoit un paramètre chemin (le nom du fichier, un texte). Elle ouvre ce fichier en lecture, lit tout le contenu, ferme le fichier, et retourne ce contenu.

lire("note.txt")  -- → le texte du fichier
