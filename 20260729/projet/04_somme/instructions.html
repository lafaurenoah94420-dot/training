Exercice 4 / 6 — Tables (listes)

Sommer une liste

ipairs + accumulateur

Le concept

Pour additionner tous les éléments, parcours avec ipairs et accumule.

function total(liste)
  local somme = 0
  for _, x in ipairs(liste) do
    somme = somme + x
  end
  return somme
end

function total(...) — sans local.

La fonction total

Elle reçoit une table liste de nombres. Elle retourne la somme de tous les éléments. Liste vide → zéro.

total({10, 20, 5})  -- → 35
total({})           -- → 0
