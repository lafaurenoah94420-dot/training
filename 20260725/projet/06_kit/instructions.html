Exercice 6 / 6 — Gestion d'erreurs

Kit manoir

pcall + error + return

Le concept

Tu combines tout : validation avec error, tentative sécurisée avec pcall, et un calcul qui refuse les mauvaises valeurs.

Instructions

Resident Evil — manoir Spencer. Trois outils pour le jeu.

Trois fonctions, toutes sans local devant.

La fonction verrou

Elle reçoit un paramètre code (un nombre). Si le code vaut exactement trois cent quatorze, elle retourne true. Sinon elle appelle error avec le texte mauvais code.

La fonction entrer

Elle reçoit aussi code. Elle tente verrou avec pcall. Si ça réussit, elle retourne le texte entree. Si ça échoue, elle retourne le texte bloque.

La fonction dose

Elle reçoit infection et antidote (deux nombres). Si antidote vaut zéro ou moins, elle appelle error avec le texte antidote vide.

Sinon elle calcule infection moins antidote. Si le résultat est négatif, elle retourne zéro (l'infection ne peut pas descendre en dessous de zéro). Sinon elle retourne ce résultat.

verrou(314)      -- → true
verrou(100)      -- plante
entrer(314)      -- → "entree"
entrer(100)      -- → "bloque"
dose(80, 30)     -- → 50
dose(20, 50)     -- → 0
dose(50, 0)      -- plante
