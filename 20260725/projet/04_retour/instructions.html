Exercice 4 / 6 — Gestion d'erreurs

Soigner ou planter

error + return

Le concept

Une fonction peut soit retourner une valeur utile, soit planter si les arguments n'ont aucun sens. C'est le duo return / error.

function ajouter(a, b)
  if b < 0 then
    error("negatif interdit")
  end
  return a + b
end

Instructions

The Last of Us : tu appliques un kit de soin. Un soin négatif n'a pas de sens.

Écris function soigner(...) — sans local.

La fonction soigner

Cette fonction reçoit deux paramètres. Le premier s'appelle vie — c'est la vie actuelle du joueur. Le deuxième s'appelle soin — c'est combien de points tu veux ajouter.

Si soin est strictement inférieur à zéro, la fonction doit appeler error avec le texte soin invalide.

Sinon, elle doit retourner la somme de vie et soin. Un soin égal à zéro est autorisé : la vie ne change pas.

soigner(50, 20)   -- → 70
soigner(10, 0)    -- → 10
soigner(50, -1)   -- plante

✅ soigner(50, -1) échoue
