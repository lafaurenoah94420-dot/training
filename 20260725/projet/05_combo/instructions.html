Exercice 5 / 6 — Gestion d'erreurs

Tenter un soin en sécurité

pcall + error

Le concept

Tu sépares deux rôles : une fonction « stricte » qui plante si l'entrée est mauvaise, et une fonction « safe » qui utilise pcall pour tenter l'action sans faire planter tout le jeu. En cas d'échec, tu gardes l'ancienne valeur.

function strict(x)
  if x < 0 then error("bad") end
  return x
end

function safe(x)
  local ok, res = pcall(strict, x)
  if ok then
    return res
  else
    return 0
  end
end

Instructions

Project Zomboid : le soin peut être invalide. Le jeu ne doit pas crasher — tu retombes sur la vie actuelle.

Écris tes fonctions sans local devant. À l'intérieur, tu peux utiliser local pour ok et res.

La fonction appliquer_soin

Elle reçoit vie et soin. Si soin est strictement inférieur à zéro, elle appelle error("soin invalide"). Sinon elle retourne vie + soin.

La fonction soin_sur

Elle reçoit aussi vie et soin. Elle appelle appliquer_soin via pcall. Si ça réussit, elle retourne le nouveau total de vie. Si ça échoue, elle retourne la vie d'origine (inchangée).

appliquer_soin(40, 30)  -- → 70
appliquer_soin(40, -5)  -- plante
soin_sur(40, 30)        -- → 70
soin_sur(40, -5)        -- → 40
