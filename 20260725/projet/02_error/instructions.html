Exercice 2 / 6 — Gestion d'erreurs

Lancer une erreur

error

Le concept

Quand quelque chose d'interdit se produit, tu peux arrêter volontairement avec error. Le programme s'arrête à cet endroit — sauf si tu as enveloppé l'appel dans pcall.

function crier()
  error("danger")
end

ok, msg = pcall(crier)
-- ok vaut false, msg contient "danger"

Instructions

L'infection est critique : le jeu doit signaler l'alerte.

Écris function alerter(...) — sans le mot local devant.

La fonction alerter

Cette fonction ne reçoit aucun paramètre. Elle doit appeler error avec le texte infection critique.

Elle ne retourne rien de spécial : son rôle est de planter volontairement pour signaler le problème.

-- après ton code, pcall(alerter) doit échouer
-- et le message d'erreur doit contenir le mot infection
